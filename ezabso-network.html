ezABSO Network Series — Encoder Multivuelta para Redes Industriales

Encoder absoluto multivuelta con salida directa a red industrial — sin batería, sin partes desechables.

Multivuelta absoluto CC-Link / PROFIBUS / EtherNet-IP / TSN

Descripción

ezABSO Network Series lleva el mismo principio de inducción electromagnética de la línea ezABSO directo a la red industrial, sin necesidad de un convertidor externo — hasta 8,778 vueltas de detección absoluta, con hasta 2,301,100,032 divisiones totales. El mismo sensor está disponible para CC-Link, PROFIBUS-DP, EtherNet/IP, y CC-Link IE TSN a 1 Gbps — el protocolo se define al momento de pedido, no cambia el hardware.

Al ser absoluto, conserva la posición real incluso si el equipo se mueve con la alimentación apagada — no requiere rehomear al reconectar.

Características principales

Vueltas totales8,778

Resistencia a vibración200 m/s²

Velocidad mecánica permisible6,000 r/min

Protocolo de comunicación

CC-Link y PROFIBUS-DP admiten hasta 42 y 124 unidades esclavas respectivamente. EtherNet/IP opera a 10/100 Mbps con hasta 3 conexiones de I/O. CC-Link IE TSN Clase B opera a 1 Gbps (1000BASE-T, full-duplex) con topología de línea, estrella, anillo o combinaciones — recomendado para control de movimiento coordinado entre múltiples ejes.
