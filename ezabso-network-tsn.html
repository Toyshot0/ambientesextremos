Descripción

Esta versión de ezABSO agrega soporte para Ethernet industrial CC-Link IE TSN Clase B, con comunicación sincronizada a 1 Gbps — ideal para líneas donde se requiere control de movimiento coordinado entre múltiples ejes.

Mantiene el mismo principio de inducción electromagnética sin partes desechables, con detección absoluta de hasta 8,778 vueltas — la posición se conserva correctamente incluso si el equipo se mueve con la alimentación apagada.
